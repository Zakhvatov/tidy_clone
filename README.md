# Tidy-клон — личный цифровой гардероб

Клон приложения Tidy для одного человека: жена вставляет ссылку на товар с Wildberries (или
загружает фото), вещь попадает в гардероб с чистым изображением и категорией, из вещей собираются
образы. Всё бесплатно, без App Store и без подписок.

**Статус: реализованы все тикеты T1–T21 (код + автотесты), приложение задеплоено.** 356 тестов в корне + 71 в воркере,
`tsc`/`build`/`lint` зелёные. Генерация переведена на IskraGen; живой прогон ждёт API-ключ.

- Приложение: https://zakhvatov.github.io/tidy_clone/ (GitHub Pages — открывается из РФ;
  сборка `BASE_PATH=/tidy_clone/`), зеркало — https://tidy-clone.pages.dev (Cloudflare Pages;
  у части российских операторов недоступно)
- Воркер-посредник: https://tidy-api.megabaff2011.workers.dev (`/health`, `/generate`, `/classify`)

Что осталось шагом человека (честно, с доказательствами в `docs/evidence/E2E-final.md`):
добавить на экран «Домой» на iPhone, замерить скорость в сети жены и решить по домену (T21),
вписать ключ IskraGen и прогнать живую генерацию по категориям (T11),
и, собственно, критерий готовности продукта — 50+ вещей, 10+ образов, неделя использования.

## Начать новую сессию

Порядок чтения — ровно такой:

1. `docs/tickets.md` — что делаем и в каком порядке. **Раздел «Решения» в начале файла — читать первым.**
2. `CONTEXT.md` — словарь домена. Слова «Вещь», «Оригинал», «AI-версия», «Пакшот», «Образ» имеют
   строгий смысл, не заменяйте их синонимами.
3. `docs/adr/` — пять решений с обоснованиями. Не пересматривать без причины.
4. `docs/architecture.md` — слои, стек, сущности домена (зафиксировано до старта кода).
5. `docs/decisions-log.md` — решения, принятые автономно, и честные ограничения (платная генерация,
   поведение локальной сети).
6. `docs/evidence/` — доказательства по каждому тикету: что проверено, какой командой, с каким результатом.
7. `docs/research-tidy-and-market.md` — разведка: Tidy, конкуренты, эндпоинты WB, техника.

Как ведётся разработка (роли саб-агентов, запуск, поллинг, приёмка) — `docs/dev-flow.md`.

## Быстрые команды

```bash
npm install            # корень
npm run dev            # локальная разработка
npm test               # 356 тестов
npx tsc --noEmit && npm run build
npm run deploy         # сборка + выкладка на Cloudflare Pages (нужен .env.local)
cd workers/api && npm test && npx wrangler deploy
```

GitHub Pages деплоится сам: `.github/workflows/deploy-pages.yml` на каждый пуш в `master`.
Нужен секрет репозитория `VITE_TIDY_CLIENT_TOKEN` и включённый Pages с источником
«GitHub Actions». Локальная проверка подкаталога: `BASE_PATH=/tidy_clone/ npm run build`.

## Что уже проверено вживую

Не предположения, а результаты экспериментов:

| Проверка | Результат |
|---|---|
| Данные товара WB по `nmId` | `basket-*.wbbasket.ru/.../info/ru/card.json`, CORS `*`, без API и токенов |
| Категория и бренд | приходят из `card.json` (`subj_name`, `selling.brand_name`) |
| Фото WB | `images/big/{n}.webp`, число фото в `media.photo_count` |
| Детектор пакшота | 20 строк по рамке изображения; кроссовки 7/7, платье 2/2, модельные 0/5 и 0/16 — угадан верно (цифры ранней разведки; воспроизводимый регресс-набор — брошь 0/1, платье 2/2, модельное 0/5: `docs/evidence/T4-T6.md`) |
| Генерация картинок | IskraGen `gpt-image-2-text-to-image`, 1K 1:1, **7 ₽ за кадр** (асинхронно: POST → polling → download) |
| Качество генерации | ghost-манекен на белом фоне, каталожный вид |
| Вырез белым ключом | ~30 строк, худи вырезано и посажено на подложку |
| Лимиты генерации | 5 одновременных задач у провайдера; наш воркер — 5 запросов/мин на IP |

Воркер-прототип живёт в `workers/ai-test/`, разведка дашборда — в `tools/cf_probe.py`.

## Что оказалось ложной тревогой

- **Картинки «обрезались»** — виноват корпоративный `Cisco AnyConnect Socket Filter` на Mac
  разработчика, не Cloudflare. Внешний сервис скачал ту же картинку целиком.
- **«Супер медленно» в Safari** — IPv6-откат: у домена есть AAAA-запись, а на Mac нет глобального
  IPv6. Chrome из-за этого вообще не открывает `*.workers.dev`. Решается доменом с выключенным IPv6,
  если подтвердится на её телефоне.

## Стек

PWA: Vite + React + TypeScript, хранилище IndexedDB (`idb`), роутинг `react-router-dom`,
PWA-слой `vite-plugin-pwa` (Workbox), хостинг Cloudflare Pages, посредник — Cloudflare Worker
(`tidy-api`), генерация — IskraGen (`gpt-image-2-text-to-image`, оплата в рублях), распознавание
категории по фото — vision-модель через воркер. Своего сервера нет, базы данных нет, аккаунтов нет.

Секреты (ключи генерации и vision-провайдера, клиентский токен) живут только в воркере; локально — в
незакоммичиваемых `.env.local` / `workers/api/.dev.vars` (образцы: `*.example` с заглушками).
