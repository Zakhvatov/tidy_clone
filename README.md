# Tidy-клон — личный цифровой гардероб

Клон приложения Tidy для одного человека: жена вставляет ссылку на товар с Wildberries (или
загружает фото), вещь попадает в гардероб с чистым изображением и категорией, из вещей собираются
образы. Всё бесплатно, без App Store и без подписок.

**Статус: требования собраны, код не начат.**

---

## Начать новую сессию

Порядок чтения — ровно такой:

1. `docs/tickets.md` — что делаем и в каком порядке. **Раздел «Решения» в начале файла — читать первым.**
2. `CONTEXT.md` — словарь домена. Слова «Вещь», «Оригинал», «AI-версия», «Пакшот», «Образ» имеют
   строгий смысл, не заменяйте их синонимами.
3. `docs/adr/` — пять решений с обоснованиями. Не пересматривать без причины.
4. `docs/research-tidy-and-market.md` — разведка: Tidy, конкуренты, эндпоинты WB, техника.

**Первая задача — T1** (скаффолд PWA и деплой на Cloudflare Pages).

## Что уже проверено вживую

Не предположения, а результаты экспериментов:

| Проверка | Результат |
|---|---|
| Данные товара WB по `nmId` | `basket-*.wbbasket.ru/.../info/ru/card.json`, CORS `*`, без API и токенов |
| Категория и бренд | приходят из `card.json` (`subj_name`, `selling.brand_name`) |
| Фото WB | `images/big/{n}.webp`, число фото в `media.photo_count` |
| Детектор пакшота | 20 строк по рамке изображения; кроссовки 7/7, платье 2/2, модельные 0/5 и 0/16 — угадан верно |
| Генерация картинок | `@cf/black-forest-labs/flux-1-schnell`, 1024×1024 за ~1.2 с, **бесплатно** |
| Качество генерации | ghost-манекен на белом фоне, каталожный вид |
| Вырез белым ключом | ~30 строк, худи вырезано и посажено на подложку |
| Лимиты Cloudflare | 10 000 нейронов/день, 100 000 запросов/день |

Воркер-прототип живёт в `workers/ai-test/`, разведка дашборда — в `tools/cf_probe.py`.

## Что оказалось ложной тревогой

- **Картинки «обрезались»** — виноват корпоративный `Cisco AnyConnect Socket Filter` на Mac
  разработчика, не Cloudflare. Внешний сервис скачал ту же картинку целиком.
- **«Супер медленно» в Safari** — IPv6-откат: у домена есть AAAA-запись, а на Mac нет глобального
  IPv6. Chrome из-за этого вообще не открывает `*.workers.dev`. Решается доменом с выключенным IPv6,
  если подтвердится на её телефоне.

## Стек

PWA: Vite + React + TypeScript, хранилище IndexedDB, хостинг Cloudflare Pages, посредник —
Cloudflare Worker, генерация — Workers AI. Своего сервера нет, базы данных нет, аккаунтов нет.
