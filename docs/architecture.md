# Архитектура (зафиксировано координатором до старта кода)

Документ снимает спорные вопросы структуры, чтобы параллельные исполнители не разошлись.
Пересмотр — только через запись в `docs/open-questions.md`.

## Слои

```
index.html
public/            манифест, иконки, _redirects (SPA-fallback для Pages)
src/
  main.tsx         точка входа, регистрация SW
  app/             роутинг, экраны, общий каркас
  domain/          словарь домена: типы, таксономия, чистые функции (без React и без сети)
  storage/         IndexedDB: схема, миграции, репозитории
  services/        сеть и внешние данные: WB, воркер, оцифровка
  ui/              переиспользуемые компоненты и токены стилей
workers/api/       воркер-посредник (Cloudflare Workers)
```

Правило зависимостей: `domain` не знает ни о чём выше. `storage` и `services` знают только `domain`.
React-компоненты не ходят в сеть напрямую — только через `services`.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Расположение приложения | корень репозитория (`package.json`, `index.html` в корне) | один проект, один деплой, не плодим вложенность |
| Сборка | Vite + React + TypeScript, `strict: true` | ADR-0001, README |
| PWA | `vite-plugin-pwa` (Workbox), `registerType: 'autoUpdate'`, версионированный прекеш | O9: новая версия подхватывается при следующем открытии |
| Роутинг | `react-router-dom`, SPA-fallback через `public/_redirects` | несколько экранов; Pages отдаёт статику |
| Хранилище | IndexedDB через `idb`, БД `wardrobe`, версия схемы — целое число с миграциями | T2, ADR-0002 |
| Изображения | `Blob` прямо в IndexedDB, не base64 | не раздувать память на 1024×1024 |
| Состояние | React Context + хуки, без Redux | масштаб — личное приложение |
| Стили | CSS-переменные из ADR-0005, CSS Modules по компонентам | системный шрифт, никаких UI-китов |
| Воркер | `workers/api`, имя `tidy-api`, маршруты `POST /generate`, `POST /classify` | T3, ADR-0003 |
| Секреты | `wrangler secret put` (`OPENCODE_API_KEY`); в репозитории только имена | секреты никогда в клиенте и никогда в git |
| Хостинг | Pages-проект `tidy-clone` | бесплатный поддомен до решения T21 |

## Домен: обязательные сущности (T2)

- **Вещь** — `id`, `название`, `категория`, `подкатегория`, `цвета[]`, `состав[]`, `сезон[]`, `бренд`,
  `источник` (`ссылка` | `фото`), `wbNmId?`, `датаСоздания`, `датаОбновления`, `idИзображений`.
- **Изображение** — `id`, `idВещи`, `роль` (`оригинал` | `ai` | `вырез`), `blob`, `ширина`, `высота`,
  `mime`, `датаСоздания`. Оригинал неизменяем и не удаляется вместе с вещью иначе как каскадом.
- **Образ** — `id`, `название`, `сезон` (`зима` | `лето` | `демисезон`), `элементы[]` (id вещи,
  позиция, масштаб, z-порядок), `обложкаИзображениеId?`, `датаСоздания`.
- **Категория** — не таблица, а константы таксономии в `src/domain/taxonomy.ts` (ADR-0004: два уровня).

## Проверяемость

`npm run build`, `npx tsc --noEmit`, `npm test` (vitest) должны быть зелёными на каждом коммите.
