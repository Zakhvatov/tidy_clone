# T1 — Скаффолд PWA и деплой на Cloudflare Pages

Проверено 2025-10-14. Деплой выполняет координатор, здесь только автоматизируемые доказательства.

## 1. Проверки зелёные

Логи: `raw/t1-tsc.txt`, `raw/t1-build.txt`, `raw/t1-test.txt`.

```
$ npx tsc --noEmit      # exit=0
$ npm run build         # exit=0, PWA generateSW, precache 14 entries, sw.js
$ npm test              # exit=0, 3 files / 9 tests passed
```

## 2. Артефакты сборки

`dist/` содержит всё, что нужно Pages:

- `manifest.webmanifest` — `name=short_name=Гардероб`, `display=standalone`,
  `background_color=theme_color=#FFFFFF`, `start_url=/`, `scope=/`, `lang=ru`,
  иконки 192/512 + maskable;
- `sw.js` + `workbox-*.js` — версионированный прекеш (`precacheAndRoute` c `revision`),
  `cleanupOutdatedCaches`, `createHandlerBoundToURL("/index.html")` (офлайн-заглушка навигации),
  `skipWaiting` + `clientsClaim`;
- `_redirects` → `/* /index.html 200` (SPA-fallback);
- `pwa-192x192.png`, `pwa-512x512.png`, `apple-touch-icon.png`, `maskable-512x512.png`;
- `index.html` c `apple-mobile-web-app-*`, `viewport-fit=cover, user-scalable=no`,
  `theme-color #FFFFFF`, `<link rel="manifest">`, `<title>Гардероб</title>`.

## 4. Деплой на Cloudflare Pages (сделал координатор)

Проект создан один раз (`--force`, потому что новый wrangler делегирует Pages в Workers):

```
$ npx wrangler pages project create tidy-clone --production-branch master --force
✨ Successfully created the 'tidy-clone' project.

$ npx wrangler pages deploy dist --project-name tidy-clone --branch master --commit-dirty=true
✨ Successfully created the 'tidy-clone' project... Uploaded 11 files
✨ Deployment complete! https://d3751e06.tidy-clone.pages.dev
```

`wrangler pages deployment list --project-name tidy-clone` подтверждает: environment `Production`,
branch `master`, status ok.

### Проверка живого сайта

Локальная сеть разработчика не отдаёт TLS до `*.pages.dev` (корпоративный Cisco AnyConnect
Socket Filter: DNS-запрос `tidy-clone.pages.dev` к локальному резолверу возвращает NXDOMAIN, TCP:443
открывается, но рукопожатие таймаутит; через DoH записи видны — `172.66.45.7`, `172.66.46.249`).
Поэтому прод проверен серверным запросом: одноразовый воркер `tidy-probe` на edge Cloudflare
запрашивал страницы. Лог: `raw/t1-pages-probe.json`. Воркер после проверки удалён
(`wrangler delete --name tidy-probe --force` → `Successfully deleted tidy-probe`).

Результат:

| Путь | Статус | Что вернулось |
|---|---|---|
| `/` | 200 | HTML 939 байт, `<title>Гардероб</title>`, ссылка на `manifest.webmanifest`, `type="module"` |
| `/add` | 200 | тот же HTML (SPA-fallback работает) |
| `/nonexistent-page-xyz` | 200 | тот же HTML — `_redirects` отдаёт приложение, а не 404 |
| `/manifest.webmanifest` | 200 | `application/manifest+json`, 622 байта |
| `/sw.js` | 200 | `application/javascript`, 1731 байт |

человека (T20).
