# T11 — Шаблоны промптов по категориям

## Что сделано и проверено

- `src/domain/prompt-templates.ts` — шаблон на каждую верхнюю категорию ADR-0004 (Верх, Низ, Платья,
  Верхняя одежда, Второй слой, Обувь, Аксессуары, Бельё) + запасной, сборка промпта из атрибутов вещи,
  ограничение длины под лимит воркера (800 символов), требование полноты вещи в кадре.
- `src/domain/prompt-templates.test.ts` — 16 тестов: шаблон есть у каждой верхней категории, промпт
  содержит признаки полноты вещи (полная вещь, вид спереди, по центру, чистый белый фон, каталожное
  фото), неизвестная категория → запасной шаблон, длина ≤ 800, цвета попадают в промпт.

```
$ npx tsc --noEmit
$ npm test   → src/domain/prompt-templates.test.ts (16 tests) passed
```

## Живой прогон по 8 категориям — ОТЛОЖЕН (не выполнен)

Требование тикета «для 8 верхних категорий генерация стабильно даёт полную вещь, а не фрагмент»
**пока не подтверждено живым прогоном**. Причина — исчерпание дневной квоты Workers AI
(`4006: you have used up your daily free allocation of 10,000 neurons`), см. `docs/decisions-log.md`, D6.
Прогон начался и упёрся в квоту: все запросы вернули либо таймаут, либо 502 `model_error`.

Что готово для повторного прогона:
- `tools/t11_generation_check.mjs` — воспроизводимый скрипт: берёт реальные карточки WB по категориям,
  строит промпт шаблоном, зовёт воркер, сохраняет JPEG в `docs/evidence/raw/t11/`, считает метрики
  рамки (переиспользует детектор пакшота) и валидность JPEG.
- Подобранные реальные nmId по категориям (из `docs/evidence/raw/t11-live.txt`): Верх `14058529`
  (Футболки), Низ `14058401` (Брюки), Платья `14058746` (Платья), Верхняя одежда `14058443` (Ветровки),
  Второй слой `14058606` (Толстовки), Обувь `14058427` (Кеды).

**Что нужно сделать для закрытия T11**: один прогон `npx vite-node tools/t11_generation_check.mjs`
после сброса суточной квоты (раз в сутки по UTC), затем заполнить таблицу вердиктов ниже.

## Косвенное подтверждение, что путь рабочий

Генерация через тот же воркер и ту же модель уже давала валидный результат до исчерпания квоты:
`POST /generate` → 200, `image/jpeg`, 1024×1024 (проверено координатором, файл `/tmp/gen.jpg`),
и позже — через edge-пробу, которая сгенерировала картинку и скормила её в `/classify`.
Это подтверждает работоспособность канала, но **не** качество по категориям.
