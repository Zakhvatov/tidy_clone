# Финальная приёмка (verify-e2e)

Проверено координатором 2025-10-14 после реализации всех тикетов T1–T21.

## Прод-сборка на Cloudflare Pages

Задеплоено: `https://tidy-clone.pages.dev` (deployment `3d004105`, branch `master`).

Локальная сеть разработчика не пропускает TLS до `*.pages.dev` (D5), поэтому прод проверен
серверным запросом с edge — одноразовым воркером `tidy-final-probe`, который после проверки удалён
(`Successfully deleted tidy-final-probe`). Сырой ответ: `raw/final-probe.json`.

| Проверка | Результат |
|---|---|
| Маршруты `/`, `/add`, `/outfits`, `/outfit/new`, `/backup`, `/help`, `/item/abc` | все `200`, HTML 921 байт |
| SPA-fallback (`_redirects`) | `/item/abc` и неизвестный путь отдают приложение, а не 404 |
| `/manifest.webmanifest` | `200`, 547 байт: `name=short_name=Гардероб`, `display=standalone`, `start_url=/`, `scope=/`, `lang=ru`, `background_color=theme_color=#FFFFFF`, иконки 192/512 (any) + 512 (maskable) |
| `/sw.js` | `200`: есть `precacheAndRoute`, `createHandlerBoundToURL` (офлайн-оболочка), `cleanupOutdatedCaches` |
| Иконки | `/pwa-192x192.png` 200 (6162 Б), `/apple-touch-icon.png` 200 (3019 Б) |
| Бандл | `/assets/index-B2-uEQNO.js`, 376 КБ: содержит URL воркера, заголовок `x-tidy-client` и маршруты `/backup`, `/help`, `/outfits`, `/add` |

## Воркер-посредник (живые запросы)

| Проверка | Результат |
|---|---|
| `GET /health` | `200 {"ok":true,"ai":true}` |
| `POST /generate` без токена | `401` (защита работает) |
| `POST /classify` с токеном, реальная картинка | `200 {"category":"Разное","subcategory":"Разное","confidence":0}` — таксономия ADR-0004, честное «Разное» для обрезанного фото |
| `POST /generate` с токеном | сейчас `502 model_error`: исчерпана дневная квота нейронов Workers AI (`4006`, D6). До исчерпания тот же вызов отдавал `200 image/jpeg 1024×1024` |
| Лимит тела | проверить с этой машины нельзя: тело >~16 КБ не доходит (D4). На edge проверено hardening-прогоном: 16384 Б → 200, 16385 Б → 413 |

## Независимый сквозной тест

`src/__independent__/e2e.test.tsx` — 28 тестов, написанных отдельным тест-агентом (не исполнителями):
сквозной путь «ссылка/фото → вырез → очередь → образ → перезапуск», негативные кейсы, проверка
заявлений из evidence по коду, производительность. Все 28 зелёные после исправления найденных дефектов.
Сырой лог первого прогона (с падениями-доказательствами): `raw/m2-m3-independent-test-log.txt`.
