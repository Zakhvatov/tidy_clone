# Открытые вопросы

Файл сохраняется как протокол — чтобы в новой сессии не поднимать эти вопросы заново.
Итоговые решения продублированы в `docs/tickets.md`, раздел «Решения».

---

## Были блокирующими

### O1 · Какие входы принимаем → **только фото (ADR-0006)**

Изменено 20.10.2026: единственный вход — «Загрузить фото». Поле ссылки WB удалено из
интерфейса; модули парсинга остаются в коде, но из UI не вызываются (удаление — отдельное
решение, после подтверждения). Vision-модель определяет категорию по фото.

### O2 · Какое изображение где → **AI-версия везде, оригинал в один тап**
В сетке и в коллаже показывается AI-версия, если она есть. Оригинал доступен переключателем в
карточке вещи. Пометка об AI живёт только в карточке — сетка должна выглядеть чисто.

### O3 · Генерация сама или кнопкой → **кнопкой**
Противоречие между ADR-0002 («только явным действием») и T10 («получает каталожное изображение»)
снято: генерация запускается нажатием, но массовая оцифровка — это одно нажатие на весь гардероб,
а не по одной вещи. Фоновой генерации не существует.

### O4 · Визуальное направление → **ADR-0005**
Белый фон, подложка `#F6F6F4`, терракотовый акцент `#C05B3F`, системный шрифт, скругления 20px,
отступы 20px, анимации 150–200 ms. Сдержанность Tidy плюс один тёплый акцент.

### O5 · Критерий готовности → **зафиксирован**
50+ вещей в гардеробе (минимум треть по ссылке), ручных правок категорий не больше 20%, 10+ образов,
неделя использования без помощи, офлайн, ни одной потерянной вещи.

## Были неблокирующими

### O6 · Что такое Образ → **название и сезон**
Название (автогенерируемое, редактируемое) и сезон: зима, лето, демисезон. Повода нет — это уже
территория AI-стилиста, которого мы выкинули.

### O7 · Онбординг → **минимальный**
Первый экран — одна кнопка «Загрузить фото». Никаких туториалов и каруселей.
(Изменено ADR-0006, 20.10.2026: раньше было «поле для ссылки и одна кнопка».)

### O8 · Резервная копия → **файл, без облака**
Облака нет вообще. Экспорт всего гардероба одним файлом и импорт, вручную.

### O9 · Обновления → **service worker с версионированием**
Новая версия подхватывается при следующем открытии приложения.

### O10 · Свой домен → **решается по T21**
Фронт уже на GitHub Pages (`https://zakhvatov.github.io/tidy_clone/`), API на Cloudflare —
домен нужен, только если придётся уходить с github.io. Если IPv6-откат тормозит — покупаем
домен с выключенным IPv6, ~200–300 ₽/год.

## Закрыты / отложены 20.10.2026

### O11 · Пикер и цена в массовой оцифровке → **опущено**
Владелец решил не переносить пикер модели и подтверждение стоимости в блок «Оцифровать всё,
где нет пакшота». Массовый запуск идёт дефолтной i2i-моделью, цена перед запуском не
показывается. Известное следствие: кнопка тратит реальные деньги, а бюджет запуска не виден
(D15). Если это раздражает на практике — вопрос поднимается заново.

### O12 · Перенос API на Яндекс-хостинг → **отложено**
Вопрос поднимался из-за зависимости от Cloudflare. Решение: не делаем сейчас, остаёмся на
Cloudflare Worker (API) + GitHub Pages (фронт). Возврат к вопросу возможен, если Cloudflare
станет недоступен из РФ или появятся деньги на платный хостинг; точные тарифы Яндекса не
проверялись. Фиксируется как отложенный, а не отвергнутый (D15).

Статистика носки и cost-per-wear · чемодан и поездки · AI-стилист · ресейл, химчистка, ремонт ·

## Юридическое

Парсинг карточек WB для личного некоммерческого использования — осознанное решение. Данные берутся
из публичной статики, авторизация не обходится. Приложение не распространяется.
