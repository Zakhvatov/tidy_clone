## Что осталось

### 1. Живая генерация (T10, T11) — ждёт ключ IskraGen

Генерация переведена с Workers AI на IskraGen (D12): `gpt-image-2-text-to-image`, 7 ₽ за кадр 1K,
асинхронно (POST → polling → download). Код и тесты готовы, боевой ключ ещё не вписан.

Когда ключ получен:

```bash
cd workers/api
npx wrangler secret put ISKRAGEN_API_KEY   # секрет прода, в git не попадает
npx wrangler deploy                        # выложить новый воркер
cd ../..
npx vite-node tools/t11_generation_check.mjs   # 8 категорий, ~56 ₽; скрипт ещё ходит через старую пробу
```

Проверка в приложении: карточка вещи без пакшота → «Сделать AI-версию», либо массовая кнопка на
экране гардероба. Перед прогоном положить на ключ 100 ₽ — это ≈14 кадров `gpt-image-2`.

Важно: локальная сеть режет ответы >~19 КБ (D7), поэтому живую генерацию с этой машины проверять
нельзя — только с чистой сети, через приложение на проде или edge-пробу. Баланс и списания видны в
`GET https://api.iskragen.ru/v1/billing/balance` (нужен `Authorization: Bearer`).

### 2. Реальный iPhone (T1, T20)

Открыть https://tidy-clone.pages.dev в Safari → «Поделиться» → «На экран Домой».
Проверить: открывается без адресной строки, работает офлайн (самолётный режим), выглядит нормально
нижняя навигация (5 пунктов).

### 3. Сеть жены и домен (T21)

Замерить скорость открытия на её телефоне в её сети. Если Safari тормозит из-за IPv6-отката
(подробности в ADR-0003 и `docs/evidence/T21.md`) — покупать домен на Cloudflare (~200–300 ₽/год)
и выключить `Network → IPv6 compatibility: Off`. У бесплатных `*.pages.dev`/`*.workers.dev` эта
настройка недоступна — зоны чужие.

### 4. Критерий готовности продукта (раздел «Решения»)

50+ вещей в гардеробе (минимум треть по ссылке), ручных правок категорий ≤20%, 10+ образов,
неделя ежедневного использования, ни одна вещь не потерялась. Это проверяется только жизнью.

## Осознанные ограничения (не дефекты)

- **AI-версия рисуется по промпту, а не по пикселям Оригинала** (D10). Модель сейчас
  `gpt-image-2-text-to-image` (D12), шаблоны промптов — T11. Риск «нарисовало другую вещь» снимается тем, что
  Оригинал хранится вечно, AI-версия помечена и её можно удалить или перегенерировать.
  Переход на image-to-image — отдельное продуктовое решение, ждёт человека.
- **Клиентский токен воркера виден в публичном бандле** (он `VITE_`-переменная). Это заслон от
  случайных сканеров плюс rate limit, а не аутентификация. Настоящая защита — Cloudflare Access/Turnstile.
- **Подложка образа живёт в `localStorage`** и в резервную копию не входит (T19) — осознанно.
- **Локальная сеть этой машины** режет TLS до `*.pages.dev` и тела >~16 КБ в обе стороны (D4/D5/D7).

## Как воспроизвести проверки

```bash
npm install && npm test && npx tsc --noEmit && npm run build && npm run lint
cd workers/api && npm install && npm test && npx tsc --noEmit

# независимый сквозной тест (написан отдельным тест-агентом, не исполнителями)
npx vitest run src/__independent__/e2e.test.tsx

# живой воркер (токен — в .env.local, он же секрет CLIENT_TOKEN воркера)
curl -s https://tidy-api.megabaff2011.workers.dev/health
```

## Как велась разработка

`docs/dev-flow.md`: координатор режет задачи, запускает саб-агентов (`tools/agents/run.sh`, роли в
`tools/agents/roles/`), поллит статус (`tools/agents/poll.sh`), принимает результат, коммитит и пушит.
Роли: исполнитель, ревьюер (2 прогона, оба нашли реальные блокеры), тестировщик (28 независимых
тестов, нашёл 3 дефекта), аудитор (2 прогона по всем тикетам). Логи всех запусков — в `.agents/logs/`
(не коммитится).
