# Визуальное направление: сдержанность Tidy, тёплый акцент, системный шрифт

Продукт делается для одного человека, и главная его ценность — вещи на белом фоне. Любой визуальный
шум конкурирует с ними. Поэтому берём то, за что Tidy хвалят даже критики — «лаконичный дизайн, нет
кучи мешающихся кнопок», — но уходим от его стерильности одним тёплым акцентом. Шрифт системный:
PWA не должна тянуть веб-шрифты ради скорости на телефоне.

## Палитра

```
Фон                 #FFFFFF
Подложка карточек   #F6F6F4
Границы             #EDEDEA
Текст               #111111
Вторичный текст     #8A8A85
Акцент (CTA, активные чипы)  #C05B3F   тёплая терракота
```

## Формы и типографика

- Скругления: карточки **20px**, чипы **12px**, кнопки-таблетки **999px**.
- Шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Text"`. Заголовки экранов **32–34px, вес 600,
  letter-spacing −0.02em**. Тело **16px**.
- Отступы: **20px** по краям, **24–32px** между секциями.
- Тени почти не используются — вместо них подложка и граница 1px.
- Иконки линейные, толщина 1.5px.
- Изображения вещей — на белом, без рамок, на подложке `#F6F6F4`.

## Анимации

Минимальные: **150–200 ms, ease-out**, только как отклик на действие. Ничего декоративного.

## Рассмотренные варианты

- **Скопировать Tidy ровно** — отвергнуто: получится безликая копия, и мы всё равно не повторим его
  полировку один в один.
- **Своё яркое направление** — отвергнуто: конкурирует с изображениями вещей, ради которых всё делается.

## Последствия

- Дизайн-система задана значениями, а не словами: следующая сессия не переизобретает палитру.
- Тёплый акцент — единственное цветное пятно. Если он начнёт встречаться часто, это ошибка, а не стиль.
- Системный шрифт означает: на iPhone всё выглядит нативно без единого килобайта шрифтов.
