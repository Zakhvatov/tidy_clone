# Категоризация: словарь таксономии WB, а не нейросеть

> Дополнено ADR-0007 (22.10.2026): добавлены верхние категории «Блузки» и «Комбинезоны»
> с подкатегориями `блузка` и `комбинезон`. Принцип двух уровней и словарь WB сохраняются.

Вещь должна попадать в категорию автоматически — это ядро продукта, ради которого всё делается.
Источник данных выбирается по стоимости и точности: у карточек WB в `info/ru/card.json` уже есть
готовые `subj_name` («Кеды», «Платья», «Броши») и `subj_root_name` («Обувь», «Одежда», «Бижутерия»).
Поэтому категория берётся **детерминированным словарём** «таксономия WB → наша таксономия», а не
распознаётся моделью. Словарь бесплатен, мгновенен, воспроизводим и не ошибается там, где данные
уже размечены продавцом. Нейросеть остаётся подстраховкой только для источников без данных — то
есть для скриншотов.

## Таксономия: два уровня

```
Верх            лонгслив, футболка, топ, кроп-топ, рубашка, свитер
Низ             джинсы, брюки, шорты, юбка
Платья          платье, сарафан
Верхняя одежда  куртка, пальто, пуховик, пиджак, тренч
Второй слой     кардиган, жилет, худи
Обувь           кроссовки, ботинки, сапоги, туфли, сандалии
Аксессуары      сумка, ремень, шапка, шарф, украшения, очки
Бельё           бюстгальтер, трусы, носки, колготки
```

Два уровня, а не один: верхний уровень задаёт порядок в гардеробе (секции-полки), нижний — работу
редактора образов (чипы подкатегорий). Один уровень не даёт ни того, ни другого.

## Рассмотренные варианты

- **Vision-LLM решает по фото** — отвергнуто как основной путь: платный вызов на каждую вещь,
  задержка и риск грубой ошибки там, где продавец уже написал «Кеды». Оставлен как запасной для
  скриншотов.
- **Полностью вручную** — отвергнуто: ручное разнесение сотни вещей по категориям и есть та работа,
  которую продукт обязан убрать.

## Последствия

- Появляется артефакт, требующий поддержки: словарь соответствий WB → наша таксономия. Его нужно
  наполнить для частых `subj_name` и предусмотреть поведение для неизвестных значений (кладём в
  «Разное» и предлагаем выбрать вручную, а не теряем вещь).
- У каждой вещи категория и подкатегория должны быть редактируемы: словарь ошибается на стыках
  («Костюмы спортивные» — это верх и низ одновременно).
- Таксономия — часть домена, а не константа в коде: она должна переживать добавление новых категорий
  без миграции данных.
